# Project Requirements

You are a senior React engineer tasked with recreating a data dashboard based on a FIFA 19 player dataset. The original Tableau workbook XML provided was truncated and did not contain the specific dashboard layout definitions. However, the datasource definition was fully intact, revealing a rich schema of player attributes. Your task is to build a comprehensive 'FIFA 19 Player Analysis' dashboard that utilizes this schema to provide meaningful insights.

Tech Stack:
- React 18+
- TypeScript
- Vite
- D3.js (v7 or similar) for visualizations (use d3-scale, d3-shape, d3-axis, d3-array primitives).
- CSS Grid/Flexbox for layout (no external UI component libraries like Ant Design).

Data Source:
- Primary File: /data/data (2).csv
- The data contains player attributes including: Name, Age, Nationality, Overall, Potential, Club, Value, Wage, Position, Preferred Foot, and various skill stats (Finishing, Dribbling, etc.).

Implementation Requirements:

1. Data Loading:
Implement a robust data loading utility using the native fetch API. The data is located at '/data/data (2).csv'. You must parse the CSV text into a JSON array of objects. Handle type conversion for numeric fields (e.g., 'Overall', 'Age', 'Potential' should be numbers, not strings).

2. Layout:
Create a responsive CSS Grid layout for the main dashboard page.
- Header: Title of the dashboard.
- KPI Section: A row of cards displaying high-level metrics.
- Main Charts Section: A 2-column grid for primary visualizations.
- Detail Section: A wide area for a detailed data table or specific breakdown.

3. Components:

a. KPICard:
- Props: title, value, format (optional).
- Display: A simple card showing the title and a large formatted value.
- Usage: Display 'Total Players', 'Average Overall', 'Average Potential'.

b. OverallHistogram (D3):
- Visual: Histogram showing the distribution of the 'Overall' rating.
- X-Axis: Overall Rating (bins).
- Y-Axis: Count of players.
- Implementation: Use d3-bin to calculate bins and d3-scaleLinear for axes. Render bars using SVG rects.

c. AgeVsPotentialScatter (D3):
- Visual: Scatter plot comparing 'Age' (X-axis) vs 'Overall' (Y-axis).
- Encoding: Color the dots by 'Potential' (using a sequential color scale like d3-interpolateViridis).
- Interactions: Add a tooltip that displays the player's Name, Age, Overall, and Potential on hover.

d. TopClubsBarChart (D3):
- Visual: Horizontal bar chart showing the Top 10 clubs by 'Average Overall' rating.
- X-Axis: Average Overall.
- Y-Axis: Club Name.
- Implementation: Aggregate data by 'Club', calculate mean 'Overall', sort descending, take top 10. Use d3-scaleBand for Y and d3-scaleLinear for X.

e. PlayerTable:
- Visual: A sortable HTML table.
- Columns: Name, Age, Nationality, Club, Overall, Potential, Value, Wage.
- Features: Basic sorting by column headers.

4. Interactions:
- Global Filters: Add a dropdown to filter the entire dashboard by 'Nationality'. When a nationality is selected, all charts (Histogram, Scatter, Bar Chart, Table) should update to reflect only players from that country.

5. Styling:
- Use standard CSS modules or styled-components.
- Ensure the design is clean, with ample whitespace and legible typography.
- Use a dark or light theme consistent with modern analytics dashboards (default to light theme with subtle borders).

Data Loading Section:
Please implement the data fetching logic as follows:

```typescript
import { useEffect, useState } from 'react';

type PlayerData = {
  [key: string]: string | number;
};

export const useFifaData = () => {
  const [data, setData] = useState<PlayerData[]>([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch('/data/data (2).csv');
        if (!response.ok) throw new Error('Network response was not ok');
        const csvText = await response.text();
        
        // Simple CSV parser
        const rows = csvText.split('\n').filter(row => row.trim() !== '');
        const headers = rows[0].split(',').map(h => h.trim());
        
        const parsedData = rows.slice(1).map(row => {
          const values = row.split(',');
          const obj: PlayerData = {};
          headers.forEach((header, index) => {
            let val = values[index] ? values[index].trim() : '';
            // Attempt to convert numeric fields
            if (
              ['Age', 'Overall', 'Potential', 'ID', 'Jersey Number', ...].includes(header) // Add other numeric keys as needed
            ) {
              const num = parseFloat(val);
              val = isNaN(num) ? val : num;
            }
            obj[header] = val;
          });
          return obj;
        });

        setData(parsedData);
      } catch (err) {
        setError(err instanceof Error ? err.message : 'An error occurred');
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, []);

  return { data, loading, error };
};
```
