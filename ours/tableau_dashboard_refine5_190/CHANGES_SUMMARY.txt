ISSUE IDENTIFIED
================================================================================

The CSV file contains a UTF-8 BOM (Byte Order Mark) character at the start.
The d3-dsv library's csvParse function was not handling this BOM, causing the
first header to be parsed as "﻿Row ID" instead of "Row ID".

This caused:
- Field lookup failures (column names didn't match)
- Silent parsing errors
- Potential all-zero charts, NaN filters, and Jan 1970 timelines

================================================================================
FIX APPLIED
================================================================================

File: src/services/dataService.ts
Function: parseCSV()

Added BOM detection and removal before CSV parsing:

  function parseCSV(text: string): RawCSVRow[] {
    // Remove BOM if present (UTF-8 BOM is 0xEF,0xBB,0xBF)
    let cleanedText = text;
    if (text.charCodeAt(0) === 0xFEFF) {
      cleanedText = text.slice(1);
    }
    
    return csvParse(cleanedText) as unknown as RawCSVRow[];
  }
