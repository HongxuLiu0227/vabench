# Project Requirements

You are a senior React engineer tasked with recreating a Tableau dashboard exactly as defined in the provided workbook XML.

## Tech Stack
- React 18+ with TypeScript.
- Vite for build tooling.
- D3.js (v7+) for visualizations (specifically `d3-scale`, `d3-shape`, `d3-array`, `d3-dsv`, `d3-format`).
- CSS for styling (CSS Modules or standard CSS). Do not use UI component libraries like Ant Design or Material UI.

## Data Loading

The primary data source is located at `/data/1.Who-PANAS - F _Visulizaton.csv`.

1.  **Fetch**: Use the native `fetch` API to retrieve the CSV file.
2.  **Parse**: Use `d3.csvParse` to convert the CSV string into an array of objects.
3.  **Type Definition**: Define a TypeScript interface `DataRow` matching the columns in the CSV (e.g., `Response ID`, `Gender`, `Age`, `Positive-Score`, `Negative Score`, etc.).
4.  **Data Transformation**:
    -   Calculate a derived field `PositiveNegativeScore` for each row: `row['Positive-Score'] - row['Negative Score']`.
    -   Calculate global aggregates:
        -   `overallPositiveCount`: Count of rows where `PositiveNegativeScore > 0`.
        -   `overallNegativeCount`: Count of rows where `PositiveNegativeScore < 0`.
        -   `totalRespondents`: Total number of records (should be 412 based on the workbook).
        -   `overallPositivePct`: `overallPositiveCount / (overallPositiveCount + overallNegativeCount)`.
        -   `overallNegativePct`: `overallNegativeCount / (overallPositiveCount + overallNegativeCount)`.

## Dashboard Layout & Components

The dashboard title is "Percent and Number of Positive and Negative in Varied Group".

Use a CSS Grid layout to approximate the Tableau layout:
- **Top Row**: Two KPI Cards (Positive and Negative).
- **Middle Row**: Two Pie Charts (Gender, Age).
- **Bottom Row**: Two Pie Charts (Marital Status, Ethnicity).
- **Right Sidebar**: Color Legends for the charts.

### Component: `KPICard`

Props: `label` (string), `value` (number), `percentage` (string), `type` ('positive' | 'negative').

**Styling & Behavior**:
- **Positive Card**:
    -   Background Color: `#29c832`.
    -   Text Color: `#ffffff`.
    -   Value Font Size: 15px (for the count) and 26px (for the percentage). Note: The XML shows two separate sheets for count and percentage, but they are visually grouped. You may combine them into one component or place them side-by-side. The XML layout places them in the same zone area.
    -   Font Weight: Bold.
    -   **Interaction**: Clicking this card should trigger a global filter to show only records where `PositiveNegativeScore > 0`.
- **Negative Card**:
    -   Background Color: `#ff3333`.
    -   Text Color: `#ffffff`.
    -   Value Font Size: 15px (count) and 26px (percentage).
    -   Font Weight: Bold.

### Component: `PieChart`

Props: `data` (array), `dimension` (keyof DataRow), `title` (string), `colorMap` (object mapping values to hex codes).

**Implementation Details**:
- Use `d3.pie()` and `d3.arc()` to render SVG paths.
- **Labels**: Display the Dimension name and the Percentage of Total (calculated as `value / 412`).
- **Filters**: Apply specific filters defined in the XML before aggregating:

    -   **Ethnicity**: Exclude "Null".
    -   **Gender**: Exclude "Null".

async function loadCsv(url: string) {
  const res = await fetch(url);
  if (!res.ok) throw new Error(`Failed to fetch ${url}: ${res.status}`);
  const csvText = await res.text();
  // Prefer a robust CSV parser (e.g. PapaParse) for production; keep a minimal parser if needed.
  const [headerLine, ...lines] = csvText.split(/\r?\n/).filter(Boolean);
  const headers = headerLine.split(",").map((h) => h.trim());
  return lines.map((line) => {
    const cells = line.split(",");
    const row: Record<string, string> = {};
    headers.forEach((h, i) => (row[h] = (cells[i] ?? "").trim()));
    return row;
  });
}
