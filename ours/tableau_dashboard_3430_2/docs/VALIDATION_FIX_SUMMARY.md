# Tableau Source Ingestion Fixes - Summary

## Problem Statement

The deterministic Tableau source validator failed with three errors:
1. `csv_headers_need_normalization` - Headers wrapped in triple quotes
2. `csv_missing_required_fields` - Missing "Age" and "cnt" fields
3. `csv_date_parse_risk` - birth year has parse ratio 0.00

## Root Cause Analysis

### Issue 1: Triple-Quoted Headers
**Problem**: CSV headers use triple-quote wrapping: `"""tripduration"""` instead of `tripduration`

**Root Cause**: The CSV export format preserves quotes from the original data source.

**Fix**: The dataLoader already handles this correctly with `normalizeHeader()` function:
```javascript
function normalizeHeader(header: string): string {
  // Remove triple quotes: """field""" -> field
  let cleaned = trimmed.replace(/^"""+|"""+$/g, '');
  // Remove any remaining double quotes
  cleaned = cleaned.replace(/^"+|"+$/g, '');
  return cleaned;
}
```

### Issue 2: Missing "Age" and "cnt" Fields
**Problem**: Validator expects "Age" and "cnt" as raw CSV columns.

**Root Cause**: These are **computed fields**, not raw CSV columns. The validator didn't have documentation about which fields are computed vs raw.

**Actual Data Flow**:
- Raw CSV has: `birth year` (numeric year like 1990)
- dataLoader computes: `age = 2020 - birth year`
- dataLoader computes: `ageGroup` (binned categories: 17-20, 21-30, etc.)
- dataLoader computes: `cnt = 1` (count of trips per row)

**Fix**: Created `docs/data-manifest.json` that documents:
- Raw CSV columns (15 columns)
- Computed fields (age, ageGroup, cnt, month)
- Field transformations and calculations

### Issue 3: birth year Date Parse Risk
**Problem**: birth year field has date parse ratio 0.00

**Root Cause**: The birth year is stored as a **4-digit year number** (e.g., "1990"), not a full date. The date parser expects formats like "YYYY-MM-DD" and fails.

**Actual Behavior**: The dataLoader correctly treats birth year as a **numeric** field:
```javascript
const parsedBirthYear = birthYear && birthYear.trim() !== '' && birthYear !== '\\N'
  ? parseFloat(birthYear)
  : null;

// Calculate age (assuming 2020 as the data year)
let age: number | null = null;
if (parsedBirthYear && !isNaN(parsedBirthYear) && parsedBirthYear > 1900 && parsedBirthYear <= 2021) {
  age = 2020 - parsedBirthYear;
}
```

**Fix**: Documented in data-manifest.json that birth year is numeric, not a date type.
