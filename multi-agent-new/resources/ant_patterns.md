# Curated Ant Design Patterns

- **Dashboards:** Use `Layout` with `Sider` + `Header` for navigation, `Grid` for responsive cards, `Statistic` + `Card` for KPI tiles, and `Tabs` for segmented views.
- **Data Tables:** Combine `ProTable` or `Table` with server-side pagination, filtering, and expandable rows. Support inline editing using `Form` + `Drawer`.
- **Forms:** Group related inputs with `Form.Item` and `Card`, leverage `Space` for spacing, and use `Steps` for progressive flows.
- **Charts:** Integrate `@ant-design/charts` components; align colors with theme tokens and provide annotations for critical thresholds.
- **Notifications:** Pair `Alert`, `Badge`, and `Timeline` components to communicate system status and historical actions.
- **Collaboration Panels:** Use `List`, `Comment`, and `Avatar` to display team updates, with `Popover` for quick actions.
- **Settings Pages:** Utilize `Tabs` + `Descriptions` for overview, and `Form` + `Switch` for toggles. Ensure advanced settings sit inside `Collapse`.
- **Dark Mode Ready:** Configure theme tokens (`colorBgContainer`, `borderRadius`, etc.) for easy light/dark switches.
