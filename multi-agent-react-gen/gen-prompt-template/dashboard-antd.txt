Build a modern analytics dashboard for a SaaS product using Ant Design (AntD). The dashboard should include:
- A sidebar navigation with icons for Dashboard, Users, Reports, and Settings
- A top bar with the app name and user avatar
- A main page with:
  - A summary section showing total users, active users, and revenue (use AntD Statistic and Card components)
  - A line chart for user activity (use AntD Chart or a compatible library)
  - A table of recent user signups (use AntD Table)
- Responsive layout for desktop and mobile
- Use TypeScript and best practices for file structure
