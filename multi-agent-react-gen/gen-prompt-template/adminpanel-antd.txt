Design an admin panel for managing a small e-commerce site using Ant Design (AntD). The admin panel should include:
- A sidebar with navigation for Products, Orders, Customers, and Analytics
- A Products page with a table of products, add/edit/delete functionality (use AntD Table and Modal)
- An Orders page with order status and filtering (use AntD Table and Tag)
- A Customers page with customer details and search
- An Analytics page with sales charts (use AntD Chart or a compatible library)
- Authentication for admin users
- Responsive layout and TypeScript
