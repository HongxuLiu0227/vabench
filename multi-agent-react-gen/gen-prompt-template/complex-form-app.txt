Create a single-page registration and onboarding form app using Ant Design (AntD) and TypeScript. The form should include:
- Multiple sections: Personal Info, Account Details, Preferences, and Confirmation
- Each section should be collapsible (use AntD Collapse)
- Use AntD Form for validation and layout
- Include custom validation for email, password strength, and phone number
- Add a progress indicator showing form completion
- Show a summary of all entered data before final submission
- Responsive design for desktop and mobile
- All logic and UI should be in a single page (no routing)
- Use best practices for file structure and code organization
