设计一个单页项目资源管理仪表盘应用，使用 Ant Design (AntD) 和 TypeScript，界面和内容全部为中文。页面应包括：
- 左侧固定侧边栏，包含菜单项：总览、项目资源、项目进度、项目统计等
- 页面顶部有系统名称（如“JARVIS”）和用户头像
- 主内容区包括：
  - 项目资源管理标题和筛选条件（时间范围、导出按钮等）
  - 项目数量统计饼图，显示不同项目类型的数量和比例
  - 项目资源投入分析（当前时间周期、上个时间周期），每个周期用饼图展示各类型投入
  - 项目资源投入对比表格，列出各项目类型的人力投入、占比、工时变化等
- 所有图表和表格均用 AntD 组件实现，数据和标签为中文
- 响应式布局，适配桌面和移动端
- 代码结构清晰，便于维护
