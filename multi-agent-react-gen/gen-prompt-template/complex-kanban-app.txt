Design a single-page Kanban board app using Ant Design (AntD) and TypeScript. The app should include:
- A board with multiple columns (To Do, In Progress, Review, Done)
- Cards for tasks with title, description, assignee avatar, and due date
- Drag-and-drop functionality to move cards between columns (use a compatible library with AntD)
- Ability to add, edit, and delete tasks (use AntD Modal and Form)
- A filter bar to search and filter tasks by status, assignee, or due date
- Responsive design for desktop and mobile
- All features and UI should be in a single page (no routing)
- Use best practices for file structure and code organization
